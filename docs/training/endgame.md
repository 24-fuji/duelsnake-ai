# 終盤の戦い方を良くするための提案

8x8 の AI は、体が長くなった終盤で、どの手を選んでも助からない状態に入り、自滅することがよくあります。
このページは、その原因の見立てと、直し方の案をまとめたものです。学習の設定と経過は [README.md](README.md)、ゲームのルールは [learn/RULES.md](../../learn/RULES.md) にあります。

## 前提: 8x8 の終盤は「埋め尽くし」より「生き残り合い」

ルール上は、お邪魔ブロック以外のマスをすべて自分の体で埋めれば勝ちです。
しかし、手元の対戦の記録 (`log/versus-20261126-014302.txt`、12.5 万試合学習した 8x8 のモデル) では、1,000 試合のうち盤面を埋めて勝った試合は 0 でした。

- 試合が終わったときの長さは平均 29〜34 で、64 マスの半分ほどです。
- 勝ち方は、相手の衝突がほとんどで、残りは時間切れのスコア勝ちです。
- 30 秒で長さを 3 から 64 まで伸ばすのは、かなり難しいです。

今の終盤は、盤面の半分ほどが体で埋まった状態で、相手より長く生き残る勝負になっています。
次の作戦は、この生き残り合いでもそのまま効きます。

- 自滅しないように、毒リンゴを取ってでも体を短くする
- 相手の逃げ道が一本になったときに、お邪魔を使って逆転を狙う
- お邪魔への備えとして、ブロック消去を持っておく

## 自滅する原因 (見立て)

1. **閉じた領域の広さが見えていない。**
   3x3 の畳み込みは、近くのマスの様子をつかむのは得意です。しかし「この先の空間は体より狭いか」は、盤面全体を数えないと分かりません。
2. **詰んだあとは、いつ死んでも報酬がほとんど変わらない。**
   負けの報酬は −50 で一定です。死ぬのを遅らせても、割引の分しか得になりません。
   実際は、粘っている間に相手が先に死ねば勝てます。しかし、その価値は学習しにくいです。
3. **原因になった手が、死ぬ何手も前にある。**
   行き止まりに入ったのは、死ぬ 5〜15 手前であることが多いと考えられます。
   `n_step: 3` と `gamma: 0.99` では、死んだことの責任がその手まで伝わるのに時間がかかります。
4. **終盤の経験が少ない。**
   試合の大半は序盤と中盤です。体が長い局面でランダムに 1 手動くと、そのまま死ぬことが多くなります。

## 提案

### 0. 死に方を分けて数える

`just versus` で衝突した試合を、次の 3 つに分けて数えます。

- **うっかり**: 死んだ手を選んだときに、まだ助かる道があった
- **詰み**: 死んだ手を選んだときには、もうどの手でも助からなかった。何手前に詰みに入ったかも数える
- **判定できず**: 探索が上限を越えて判定できなかった

おっしゃる「仕方なく自滅」は詰みのほうです。
この割合と、何手前に詰みに入ったかが分かれば、下の提案のどれが効くかを判断できます。
`just versus` に実装しました。測り方と 8x8 での結果は、下の「[提案 0 の測り方と結果](#提案-0-の測り方と結果)」にあります。

### 1. 推論時の安全装置 (学習し直さなくても効く)

行動を選ぶ前に、ルールで危ない手を外します。外すのは次の手です。

- 次の一手で衝突する手
- その方向に進むと、行けるマスが体の長さより少なく、尻尾にもたどり着けない手

残った手の中から、Q 値が最大の手を選びます。

- 長所: 学習し直さなくても、今のモデルの自滅がすぐ減ります。
- 短所: 学習側 (`learn/src/arena.rs`) と Web 側 (`web/src/ai/`) の両方に、同じ処理を入れる必要があります。また、AI の判断の一部を手書きのルールが担うことになります。

### 2. 観測に「空間の広さ」を足す (本命)

状態ベクトルに、次の特徴を足します。

- 上下左右それぞれについて、その方向に進んだときに行けるマスの数 ÷ マス数 (塗りつぶしで数える)
- 上下左右それぞれについて、その方向に進んだあと、自分の尻尾にたどり着けるか。体は尻尾から順に空いていくことも考えて判定する
- いちばん近い毒リンゴまでの、壁と体を避けた距離
- 相手について同じもの (相手が一本道に追い込まれていることが分かり、お邪魔を使う合図になる)

8x8 なら、計算はわずかです。
観測の仕様が変わるので、`learn/src/env/observation.rs` と `web/src/ai/observation.ts` を揃えて直し、RULES.md の 10 章も直して、学習し直します。

### 3. 報酬で「空間を保つこと」を教える

Φ を次のように決めます。

> Φ = min(行けるマスの数 ÷ 長さ, 1) + 尻尾にたどり着けるか (0 か 1)

1 手ごとに γΦ(s') − Φ(s) を報酬に足します (potential-based shaping)。

- この形の報酬なら、最適な戦い方は変わらないことが理論で示されています。そのため、報酬の抜け道を突いた変な動きが出にくいです。
- 今の引力・斥力 (`reward.force`) と同じ考え方なので、並べて入れられます。
- 毒リンゴを取ると体が 2 マス縮み、Φ が上がります。追い込まれたときに毒リンゴを取りに行く動きが、自然に出るはずです。毒リンゴの報酬 (−1) を直接変えるより素直です。

### 4. 終盤を多く学習させる

- **途中の局面から始める**: 自己対戦の途中で、体が長くなった局面 (たとえば長さ 25 以上) を取っておきます。試合の 2〜3 割を、その局面から始めます。
- **ランダムな手は安全な手から選ぶ**: ε でランダムに動くときは、すぐには死なない手の中から選びます。こうすると、長い体の終盤の経験が、ランダムな手で途切れずにたまります。
- **数手前の判断に責任を伝えやすくする**: 優先度付きのリプレイ (prioritized replay) にするか、`n_step` を 5〜10 に伸ばします。

### 5. お邪魔とブロック消去の作戦

ルール上、次の点に気をつけます。

- **お邪魔ブロックは、相手のフィールドの空きマスのどこかにランダムに置かれる。**
  そのため、相手の空きマスが少ないほど、ブロックが逃げ道をふさぐ確率が上がります。「相手が追い込まれるまで、使わずに持っておく」のが強いはずです。
  提案 2 で相手の空き具合を観測に入れれば、この合図を学べます。
- **持てるアイテムは 1 つだけ。**
  ブロック消去を持っている間にお邪魔を取ると、ブロック消去がお邪魔で上書きされます。ブロック消去を保険にするなら、お邪魔を避けて動く必要があります。
- **お邪魔ブロックも「埋めた」の判定に数える。**
  盤面がほぼ埋まった相手にお邪魔を使うと、相手が埋めて勝つのを早めることがあります。

自己対戦では、相手はいつも同じネットワークです。そのため、お邪魔を使う作戦とそれに備える作戦が、片寄ったまま固まりやすくなります。
過去のモデルを何体か取っておき、ときどきそれと対戦させる (相手のプール) と、片寄りにくくなります。

## 進める順番の案

1. **提案 0** で死に方の内訳を測る
2. 詰みが多ければ、**提案 2 と 3** を一緒に入れて、8x8 を学習し直す。旧モデルとの勝率に加えて、詰みの割合が下がるかを見る
3. 終盤の上達が遅ければ、**提案 4** を足す
4. 生き残れるようになってから、**提案 5** のアイテムの作戦を見る
5. Web の AI だけでも早く良くしたいなら、**提案 1** を並行して入れる

## 提案 1 と提案 2・3 を比べる実験

下の提案 0 の結果からは提案 2・3 が本命に見えますが、念のため提案 1 も試し、両方を同じ物差しで比べます。

### ブランチ

| ブランチ | 中身 |
|---|---|
| `experiment/endgame-compare` | 比べるための道具 (下の `--time-limit` など)。提案 1 と提案 2・3 のブランチはここから切り、結果が出たらここに両方を合わせて比べる |
| `experiment/endgame-safety` | 提案 1 (推論時の安全装置)。学習し直さない |
| `experiment/endgame-space` | 提案 2 (観測に空間の広さを足す) と提案 3 (空間を保つ報酬)。学習し直す |

提案 2 と 3 は、それぞれ単独でも、両方一緒でも学習できるようにします。どれが効くかは学習してみないと分からないので、設定で切り替えて比べます。

### 制限時間を外したときのことも考える

30 秒の制限時間は、今後撤廃するかもしれません。撤廃すると、10x10 以上の盤面でも体が長くなり、8x8 と同じ終盤の自滅が勝敗を決めるようになります。
そのため、どの提案も盤面の大きさによらず動くように作り、比べるときも 8x8 だけでなくほかの盤面と長い制限時間で測ります。

`just versus --time-limit <秒>` で、制限時間だけを変えて対戦できます (学習し直す必要はありません)。
ただし、モデルは学習したときの制限時間で残り時間 (`time_remaining`) を見ているので、制限時間を延ばすと残り時間の減り方がゆっくりになります。

8x8 のモデル同士を制限時間 120 秒で 200 試合対戦させると、すべての試合が衝突で決着しました (平均 293 ティック = 29 秒)。
制限時間を外すと、時間切れのスコア勝ちは無くなり、終盤に自滅しないことがそのまま勝ち負けになります。

### 比べ方

盤面ごとに、次の 2 つの制限時間で `just versus` を実行します。

```sh
just versus --size 8-8 --games 2000                     # 今のルール (30 秒)
just versus --size 8-8 --games 2000 --time-limit 300    # 制限時間を外したときに近い条件
```

見るのは、main のモデルに対する勝率と、衝突した試合の内訳 (うっかり・詰みの数と、何手前に詰みに入ったか) です。

## 提案 0 の測り方と結果

### 測り方

- `just versus` は、ヘビが行動を決めるたびに、そのときのフィールドの様子を取っておきます。取っておくのは、体・伸びる予定・直前に進んだ方向・お邪魔ブロックです。
- ヘビが衝突したら、死んだ手を選んだときの様子から、まだ助かる道があったかを探索で調べます。
  - 「助かる道」は、今の体がすべて退くまで (長さ + 伸びる予定の手数だけ) 動き続けられる経路とします。体は尻尾から順に空いていくので、その順番も考えます。伸びている途中で盤面が埋まる経路も、助かる道に数えます。
  - 次のものは考えない近似です。
    - 経路の途中でアイテムを取ったときの効果 (リンゴで伸びる、毒リンゴで縮む)
    - これから置かれるお邪魔ブロック
    - 手持ちのブロック消去を使うこと
  - そのため、毒リンゴを取れば抜け出せた場合も「詰み」に数えます。
- 助かる道があれば「うっかり」です。
- 無ければ「詰み」です。さかのぼって、助かる道があった最後の判断を探します。その判断で選んだ手が詰みに入った手で、それが死んだ手の何手前かを数えます。
- 探索は 1 回 20 万局面までです。越えたら「判定できず」にします。
- 学習中の評価 (1 万試合ごとの旧モデルとの対戦) では、時間を増やさないように調べません。

実装は [learn/src/trap.rs](../../learn/src/trap.rs) です。

### 8x8 での結果 (2026-11-27)

`just versus --size 8-8` で、main のモデル (旧モデル、240 万試合学習) と今の 8x8 のモデル (新モデル、26 万試合学習) を 1,000 試合対戦させました。
新モデルの勝率は 81.7% ± 2.4% でした。

| | 新モデル | 旧モデル |
|---|---|---|
| 衝突した試合 | 144 | 726 |
| 壁 / 自分の体 / お邪魔ブロック | 26 / 108 / 10 | 105 / 583 / 38 |
| 衝突したときの平均の長さ | 36.3 | 35.8 |
| うっかり | 31 (21.5%) | 257 (35.4%) |
| 詰み | 113 (78.5%) | 469 (64.6%) |
| 判定できず | 0 | 0 |
| 詰みに入ったのは 1 手前 / 2〜5 手前 / 6〜10 手前 / 11 手以上前 | 41 / 53 / 14 / 5 | 180 / 222 / 60 / 7 |
| 詰みに入ったのは平均何手前か | 3.3 | 3.0 |

読み取れること:

- **新モデルの衝突の約 8 割は詰み**です。「最後に仕方なく自滅する」という見立てと合っています。
  衝突したときの長さは平均 36 で、64 マスの半分を超えています。
- **詰みに入ったのは、ほとんどが死ぬ 5 手以内**です (113 のうち 94)。何手も前の判断が原因になった詰みは少ないです。
  そのため、数手前の判断に責任を伝える工夫 (提案 4 の `n_step` を伸ばすこと) より、**今いる空間の広さが見えること (提案 2・3) のほうが効きそう**です。
- **うっかりも 2 割あります。** 助かる道があったのに、衝突する手を選んでいます。
- うっかりは死んだ手のときに、詰みは数手前の判断のときに、それぞれ助かる道がありました。そのため、この探索をそのまま使って行動を選び直す安全装置 (提案 1) を入れれば、この 144 試合の多くは避けられた可能性があります。
  ただし、上の近似 (アイテムの効果やお邪魔ブロック) の分は避けられません。
